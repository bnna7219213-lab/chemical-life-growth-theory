# Python 模块规划

代码在模型规格达到 v0.1 后实现。首轮优先可解释的无空间随机模型，不追求模拟“完整生命”。

| 模块 | 责任 |
|---|---|
| `states.py` | 细胞/系统状态与状态标签 |
| `parameters.py` | 参数、来源标签、先验范围和配置读取 |
| `transitions.py` | 状态转移率与概率规则 |
| `resources.py` | 物质和可用能量的开放系统收支 |
| `simulator.py` | 随机事件调度和轨迹采样 |
| `metrics.py` | 群体比例、功能代理、恢复、滞后和不确定性 |
| `io.py` | 数据读写、运行配置、结果元信息 |
| `visualize.py` | 轨迹、分布和敏感性图 |

建议先实现一个小状态数的离散或连续时间模型；空间代理模型作为后续版本。每次运行保存参数快照、随机种子、代码版本和数据来源。
