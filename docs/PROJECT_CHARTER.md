# 项目章程

## 工作名称

**新的生命形态与成体生长理论：化学视角** (*Chemical Perspectives on New Life Forms and Adult Growth Theory*)。仓库 / Python distribution 名为 `chemical-life-growth-theory`。本标题表达长期理论方向；当前阶段以小鼠肠上皮为首个已知系统，开展化学信号、反应/资源代理与组织状态转移的建模和数据对照。

## 核心问题

化学结构、分子反应与结合、物质和能量通量，如何与信息继承、细胞间信号及随机性共同产生组织状态和成体生长？哪些关系能在已知组织中量化，哪些仍属理论假设？

## 工作假设

1. DNA 序列不是独立运行的指令集；它通过转录、翻译、代谢和反馈网络影响细胞状态。
2. 细胞命运变化是条件依赖的随机转移；环境和信号可改变转移概率，不保证逐细胞确定性结果。
3. 组织是开放系统，持续交换物质与能量；稳态依赖输入、转化、输出和反馈。
4. 某些表达、代谢和表观遗传状态具有可逆性；DNA 序列改变、细胞组成改变和组织结构损伤需要单独建模，不能假定可随信号撤除而倒转。

## 比较对象

- **小鼠肠上皮（首要对象）：** v0.1 唯一的建模对象。选择理由：细胞周转快（4–5 天）、损伤—再生为经典局部信号调控案例、H3K36 甲基化等表观遗传与可塑性的公开数据充分，便于行为对照。
- **硅基器件：** 仅作为"有信息处理与能量消耗、但无代谢与繁殖"的工程对照，**不建模**。
- **假设性硅基生化：** 仅在 THEORY_MAP.md 做溶剂、反应网络、能量耦合等约束层面的理论讨论，**不做具体模型**；目前没有已知实例。

## 范围

第一阶段仅建立小鼠肠上皮的一个无空间随机状态转移模型，含 3–4 个抽象状态。空间邻域、具体分子网络、跨组织信号、硅基器件与替代生化分析**均不在 v0.1 范围**。

## 后续建模重心

后续版本优先把抽象输入和资源变量逐步落实到化学对象：候选分子或分子池、反应/结合关系、动力学参数、跨边界通量及能量约束。参数必须注明物种、组织、测量条件、证据类型和不确定性。对目前没有数据支持的环节，应保留为显式假设，不以“化学视角”为由填入未经验证的机制。

线性、指数等转移率只是候选数学表达。选择依据应包括化学机制、可观测数据、可辨识性和敏感性，而不是形式上的简洁或直觉。

## 远期愿景与当前边界

“从零形成新的可生长生命形态”是远期科学问题，不是当前阶段的工程承诺。一个数学模型或计算机模拟不是生命体，也不能证明某个化学体系能自主代谢、繁殖和演化。当前成果目标是建立定义、模型、数据地图与可证伪预测。

“造物主”可作为哲学隐喻；科学上的目标是理解并有限度地控制过程。预测能力不等于完全控制，局部调控也不意味着能独立于整体生理环境。

## 阶段性成功标准

- 有公开、可审阅的术语和边界定义。
- 数学状态、概率转移、资源收支及其假设可追踪。
- Python 模拟能复现参数变化下的分布结果，并显式报告不确定性。
- 结论区分已知证据、模型推论与纯理论猜想。
