# 数据计划

## 原则

- 首轮先建数据来源目录和变量字典，不急于合并异质数据。
- 优先使用公开论文、补充数据、公开数据库和可复现的模型数据。
- 每条数据保留来源、物种、组织、测量方法、时间尺度和不确定性。
- 把实验观测、研究者解释和本项目建模假设分开记录。
- 不纳入可识别的个人健康数据。

## 候选锚点

1. **最小细胞模型：** JCVI-syn3A 4D 全细胞模型，包含遗传信息处理、代谢、细胞生长和分裂，可用于学习多尺度模型如何与实验结果对照。它是模型参照，不是局部人体组织数据。DOI：<https://doi.org/10.1016/j.cell.2026.02.009>
2. **合成原始细胞：** 脂质体内 DNA 自我复制和适应性演化的研究，用于定义"生命功能模块"与"完整生命体"的差异。DOI：<https://doi.org/10.1038/s41467-024-53226-0>
3. **首个建模对象：小鼠肠上皮。** 第 1 周已选定组织；需检索其 H3K36 甲基化、YAP/TAZ 力学信号、Wnt 梯度、损伤—再生时间序列中的细胞状态分布与恢复曲线。主要参考文献：
   - H3K36 甲基化调控肠上皮可塑性与再生：<https://doi.org/10.1038/s41556-024-01580-y>
   - 基质黏弹性通过表观遗传调控可塑性：<https://doi.org/10.1038/s41467-025-59190-7>
4. **更大规模单细胞图谱：（v0.2+ 规划）** 如 Human Cell Atlas 肠相关数据集、小鼠 Tabula Muris；仅在明确范围与许可后才纳入。

## 数据表字段

| 字段 | 说明 |
|---|---|
| `source_id` | DOI、数据库 accession 或稳定链接 |
| `system` | 物种、器件、细胞模型或理论体系 |
| `tissue_or_module` | 组织/细胞类型/器件模块 |
| `condition` | 基线、损伤、信号输入或环境条件 |
| `timepoint` | 采样时间或模拟时间 |
| `measurement` | 观察变量与单位 |
| `uncertainty` | 误差、范围、样本量或定性可信度 |
| `evidence_type` | 实验、模拟、综述背景或项目假设 |
| `license_notes` | 数据再利用条件 |

## 文件约定

- `data/raw/`：原始公开数据的只读副本及来源记录。
- `data/processed/`：清洗后的衍生数据，附处理脚本和版本说明。
- 不把数据手工复制进代码；程序从配置读取路径。
