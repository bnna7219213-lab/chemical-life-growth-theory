# 理论知识图谱 & 学习顺序

按"基础 → 细胞 → 组织 → 可计算控制"顺序学习。首轮优先"化学与能量"到"组织层"，硅基生命只做约束分析，不假装有完整生物学理论。

---

## 1. 化学与能量基础

- 分子结构、共价/非共价相互作用、酸碱与氧化还原。
- 化学动力学、催化、反应平衡与远离平衡的反应网络。
- 自由能、能量耦合、物质流和开放系统稳态。
- 膜、浓度梯度、溶剂效应与分子扩散。

**直接证据：** 化学平衡常数、自由能、膜扩散系数均有实验室测量。**待检验假设：** 组织模型中能否用单一代理资源池 $r(t)$ 替代多维代谢池，取决于敏感性分析。

---

## 2. 细胞信息与状态

- DNA/RNA 信息流、基因调控网络、转录因子和信号转导。
- 表观遗传状态、染色质结构、细胞身份与可塑性。
- 细胞周期、分裂、死亡、分化、迁移和细胞间通信。
- 代谢网络与能量供给对基因表达、合成和修复的约束。

**直接证据：**
- DNA 序列与基因调控关系（GFP 报告基因、ChIP-seq、ATAC-seq）；
- 表观遗传修饰（H3K36me3、H3K27me3、DNA 甲基化谱）与细胞状态的关联——参考文献 [6]（`REFERENCES.md`）是本项目的直接证据锚点；
- JCVI-syn3A 代谢重建——参考文献 [4]。

**待检验假设：**
- "DNA 序列提供遗传信息 → 细胞状态"这一通路，在模型里是否可简化为 $u(t)$、$r(t)$ 两类代理信号？需要与数据对照；
- 细胞状态是否能以 3–4 个离散类别近似？实际操作定义尚无数据支撑。

---

## 3. 组织层和材料环境

- 细胞外基质的成分、拓扑、黏弹性和力学感知。
- 组织形态发生、空间梯度、邻域效应、稳态与再生。
- 细胞群体异质性、克隆扩张、随机转移和选择。

**直接证据：**
- 基质黏弹性通过 YAP/TAZ 通路影响细胞命运（力学转导），多项独立研究证实；
- 肠上皮隐窝—绒毛轴的 Wnt 与 Notch 梯度已通过荧光报告基因可视化（`REFERENCES.md` 相关文献）。

**待检验假设：**
- 能否把力学环境与化学信号合并为单一抽象输入 $u(t)$？这取决于对照数据能否在两类扰动下给出可分离响应；
- v0.1 模型不模拟空间，空间邻域效应能否通过群体平均的代理输入近似？

---

## 4. 数学与计算

- 连续时间 Markov 过程、主方程和 Gillespie 随机模拟。
- 常微分方程、反应网络、质量守恒与参数估计。
- 空间随机过程、格点/代理模型、扩散与反应耦合。
- 敏感性分析、可辨识性、不确定性传播和模型比较。
- 控制理论：输入信号、观测量、反馈、滞后、可控性与可观测性。

**直接证据：** Gillespie 算法、ODE 求解、敏感性分析等方法论成熟。**待检验假设：** 抽象转移率形式 $q_{ij}(t)=q^0_{ij}\exp(...)$ 能否捕捉真实调控网络的非线性特征？可用 AIC/BIC 对比替代形式。

---

## 5. 生命边界比较

- 最小细胞、合成原始细胞和细胞外无细胞系统。
- 信息、代谢、隔室化、自我维护、繁殖与达尔文式演化的操作性定义。
- 硅基化学的溶剂相容性、反应多样性、稳定性、催化和产物排出约束。
- 区分"硅基器件""含硅的碳基生物"和"假设性硅基生命"。

**直接证据：**
- JCVI-syn3A 4D 全细胞模型——参考文献 [1]；
- 脂质体自复制 DNA 的适应性演化——参考文献 [2]；
- 基质黏弹性对表观遗传和细胞可塑性的调控——参考文献 [5]。

**待检验假设：**
- 参见 `PLAN.md` 的"长期探索路径"；当前 v0.1 **不**进入替代生化或新生命形态。

## 已知证据 vs 待检验假设（要点摘录）

| 类别 | 直接证据 | 本项目待检验假设 |
|---|---|---|
| DNA-状态关系 | 基因调控、表观遗传修饰均已测量 | 能否简化为 $u(t)$、$r(t)$ 代理？ |
| 力学-可塑性关系 | YAP/TAZ 通路、H3K36me3 变化 | 能否与化学信号合并为单一输入？ |
| 离散状态近似 | 单细胞 RNA 测序可识别细胞类型 | 3–4 类离散近似是否足够？ |
| 随机性 | 基因表达噪声已知存在 | 白噪声/ Poisson 近似能否捕捉？ |
| 可逆性 | 肠上皮损伤后再生的已知恢复曲线 | 撤除输入后模型是否部分恢复？ |
| 硅基生化 | 无已知实例 | v0.1 不做模型，仅理论讨论 |

## 核心概念图

```text
底物结构与溶剂
        ↓
反应速率、催化与能量耦合
        ↓
基因调控 / 代谢 / 膜与梯度       ← 以上三层：直接证据充分
        ↓
细胞状态转移（概率 + 历史）      ← 本项目建模对象
        ↓
局部相互作用与空间组织          ← v0.1 仅通过代理输入近似
        ↓
组织功能、稳态或再生            ← 与参考文献 [6] 行为对照
        ↺ 环境反馈与物质能量通味
```
